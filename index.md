# Hour of Micro:bit

Introduction Micro:bit

In the next hour we will introduce you to the BBC Micro:bit, an amazing, tiny computer that you can program!

## What You'll Learn

### Learn Programming
You can program the microbit in multiple languages, including Python, Javascript and Blocks.

### Get Started with Robotics
The Micro:bit is a tiny computer which you can make robots with.

### Program with Friends
Micro:bits can communicate with each other, so you can write programs with your friends.
