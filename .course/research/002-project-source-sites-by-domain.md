# Project Source Sites by Domain

Catalog of interesting sites to revisit when selecting specific projects for each module.

## micro:bit Projects (Modules 1–3)

### Official micro:bit Foundation
- **[Make it: code it](https://microbit.org/projects/make-it-code-it/)** — 123+ quick projects, searchable by topic, level, language, and micro:bit feature. The primary project library. Covers everything from simple LED displays to radio communication and sensors. **Best for:** browsing by concept when we know what we want to teach.
- **[MakeCode Projects](https://makecode.microbit.org/projects)** — Categorized into Tutorials, Games, Radio Games, Data Logging, Fashion, Music, Toys, Science, Tools. Includes step-by-step guided tutorials. **Best for:** finding polished, tutorial-ready projects.
- **[MakeCode Examples](https://makecode.microbit.org/examples)** — Shorter code examples, less tutorial-style. **Best for:** reference when building our own lessons around a concept.
- **[First Lessons sequence](https://microbit.org/teach/lessons/first-lessons-with-makecode-and-the-microbit/)** — 6-project pathway (name badge → animation → emotion badge → step counter → nightlight → rock paper scissors). **Best for:** proven beginner sequence we can reference for our foundational modules.

### Third-Party Collections
- **[awesome-microbit (GitHub)](https://github.com/carlosperate/awesome-microbit)** — Curated list of micro:bit resources, projects, and tools. Community-maintained. **Best for:** discovering lesser-known projects and tools.
- **[Seeed Studio: 27 micro:bit Projects](https://www.seeedstudio.com/blog/2019/12/10/top-25-microbit-projects-for-beginners-2019/)** — Showcase of beginner-to-intermediate projects. **Best for:** inspiration and seeing what's popular.
- **[IT Pro: 15 Top micro:bit Projects](https://www.itpro.com/desktop-hardware/26289/13-top-bbc-micro-bit-projects)** — Curated highlights. **Best for:** quick scan of standout project ideas.

## Arcade Games (Module 4)

### Official MakeCode Arcade
- **[Arcade Projects](https://arcade.makecode.com/projects)** — Beginner Skillmaps, Next Level Skillmaps, Tutorials, Multiplayer Tutorials. The main hub. **Best for:** structured game-building tutorials we can adapt.
- **[Arcade Tutorials](https://arcade.makecode.com/tutorials)** — Includes "Intro to MakeCode Arcade," "Chase the Pizza," "Collect the Clovers," and more. Step-by-step guided. **Best for:** ready-to-use game tutorials.
- **[Beginner's Guide Skillmap](https://arcade.makecode.com/skillmap/educator-info/basic-map-info)** — 11 tutorials, ~145 minutes, ages 11–15. Three categories: Storytelling, Clicker Games, Collector Games. **Best for:** a proven pedagogical sequence for game dev beginners. Very relevant to our age group.
- **[Arcade Courses](https://arcade.makecode.com/courses)** — Full CS courses built around game creation, including Intro to CS with Arcade. **Best for:** understanding concept progression in game-based CS teaching.
- **[Multipart Tutorials](https://arcade.makecode.com/multipart-tutorials)** — Longer, multi-step game builds. **Best for:** more ambitious projects for students who want to go deeper.

### Educator Resources
- **[Arcade Educator Page](https://arcade.makecode.com/educators)** — Teacher guides, classroom tips. **Best for:** instructor guide material.

## Cutebot Robotics (Module 5)

### Elecfreaks Official
- **[Cutebot Wiki (old)](https://www.elecfreaks.com/learn-en/microbitKit/smart_cutebot/index.html)** — Full case library with 15+ numbered tutorials (motor control, line following, obstacle avoidance, remote control via accelerometer, joystick, IR). Includes both MakeCode blocks and Python. **Best for:** the definitive Cutebot tutorial collection. This is our primary source for robotics projects.
- **[Cutebot Wiki (new)](https://wiki.elecfreaks.com/en/microbit/microbit-smart-car/microbit-smart-cutebot/)** — Updated wiki with introduction and cases. **Best for:** checking for newer content.
- **[Cutebot Pro](https://shop.elecfreaks.com/products/elecfreaks-smart-cutebot-pro-v2-programming-robot-car-for-micro-bit)** — Newer version with more features. **Best for:** knowing what hardware options exist if the program upgrades.

### Other Robotics Resources
- **[Liverpool Cutebot Resources](https://outreach.csc.liv.ac.uk/resources/cutebots/)** — University-developed classroom lessons for Years 7–9. Structured for 60–90 min sessions with pairs of students. **Best for:** proven classroom-tested lesson structure for robotics.
- **[IET Robot Buggy](https://education.theiet.org/secondary/teaching-resources/programming-the-robot-buggy-bbc-microbit/)** — KS3 activity for programming a micro:bit robot buggy. Not Cutebot-specific but similar concepts. **Best for:** alternative approaches to teaching robot programming.

## Cross-Domain
- **[Code.org Physical Computing](https://code.org/en-US/curriculum/maker)** — micro:bit integrated with Code.org's CS curriculum. **Best for:** seeing how another major platform integrates micro:bit into a broader CS sequence.
- **[Cyber Arcade (Maker Ed)](https://makered.org/resources/cyber-arcade-programming-and-making-with-microbit/)** — Combines micro:bit + MakeCode Arcade for ages 12–14. **Best for:** the closest comparable program to ours in concept.
