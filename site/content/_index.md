Introduction to the BBC Micro:Bit, an amazing, tiny computer that you can program!

## What You'll Learn

### Learn Programming
You can program the Micro:Bit in multiple languages, including Python, Javascript and Blocks.

### Get Started with Robotics
The Micro:Bit is a tiny computer which you can make robots with.

### Program with Friends
Micro:Bits can communicate with each other, so you can write programs with your friends.
